レシートプリンターとキャッシュドロアを買ったものの、「どのケーブルをどこにつなぐの？」「アプリのどこで設定するの？」と手が止まることはありませんか。Airレジの公式トレーニング動画「周辺機器との接続設定をおこなう」では、例としてセイコーインスツルのレシートプリンター「RP-F10シリーズ」と、キャッシュドロア「DRW-A01」の組み合わせを使っています。

![カウンターに並ぶタブレットのレジ、キャッシュドロア、ケーブルでつないだレシートプリンターと予備のロール紙の手描きイラスト](/images/posts/airregi-printer-drawer-setup-1.webp)

この記事では、その組み合わせのつなぎ方を、動画と公式ヘルプで確かめた順番にまとめました。手順の図は、機器のボタンの並びと画面のボタンの場所・名前を描いた配置図です（実際の画面ではありません。2022年ごろの公式動画をもとにしているので、今のアプリと違うことがあります）。mPOP など他の機器を使う場合は、公式動画でも案内しているとおり、Airレジの「使い方・よくあるご質問」で機種ごとのページを見てください。

## 買う前に確かめたい、RP-F10の型番

公式ヘルプ「セイコー（RP-F10）接続方法」によると、Airレジとつないで使える RP-F10 は **USB type-C PD モデル（型番 RP-F10-W27J1-5 / RP-F10-K27J1-5）** です。それ以外の型番は動作確認の対象外とされています。中古品やネットで買うときは、型番の末尾まで見比べておくと安心です。

## 1. プリンターとドロアをケーブルでつなぐ

公式動画では、最初に **付属のケーブルでプリンターとドロアをつなぎます**。プリンターの背面にケーブルを挿せば、プリンターとドロアの接続は完了です。ドロアは iPad と直接つなぐのではなく、プリンターを通して開け閉めする形になります。

![プリンターの背面とキャッシュドロアを、付属のケーブルでつなぐ配置図](/images/posts/airregi-printer-drawer-setup-step1.webp)

どの差し込み口に挿すかは、機種の取扱説明書で確かめてください。

## 2. ロール紙をセットする

RP-F10 は紙幅80mmと58mmのどちらでも使えて、初期設定は80mmです。公式ヘルプでは、**使い始めたあとに紙幅を切り替えると故障の原因になる**ので、最初に決めるよう案内しています。

80mmの場合の手順は次のとおりです。

1. グレーのレバーを押し下げて、前面のカバーを開ける
2. ロール紙が斜めにならないように入れる（印字面が外巻きのもの）
3. 紙の端をまっすぐ引き出して、カバーをしっかり閉める

58mmで使う場合は、付属のパーテーションプレートを左右に取り付けてから紙を入れます（右側用の方が背が高い）。

## 3. iPad・iPhoneとつなぐ（Bluetoothか有線）

### Bluetoothでつなぐ場合

1. プリンターの電源が切れた状態で、電源スイッチを7秒以上押し続ける（約60秒間、ペアリングを待つ状態になり、ランプが1秒に2回点滅する）

![プリンターの正面。右下の電源ボタンを7秒以上押すと、上のランプが点滅する配置図](/images/posts/airregi-printer-drawer-setup-step2.webp)

60秒を過ぎると待つ状態が終わるので、iPad の設定画面を先に開いておくとあわてずにすみます。

2. iPad・iPhone の「設定」→「Bluetooth」をオンにする
3. 「デバイス」の欄から「RP-F10」を選ぶ
4. 「RP-F10」の右端に「接続済み」と出たら完了（公式ヘルプによると、プリンターのランプも点滅から点灯に変わります）

![iPad の設定のBluetoothで、デバイスの欄のRP-F10を選び、接続済みになるまでの配置図](/images/posts/airregi-printer-drawer-setup-step3.webp)

### 有線（USBケーブル）でつなぐ場合

- プリンター側は USB Type-C のケーブルを使う（Lightning や USB Type-A は使えない）
- iPad・iPhone 側は、端末に合わせて Lightning か USB Type-C。Lightning は Apple 純正品か MFi 認証品、Type-C はデータ通信ができるケーブル（充電専用のケーブルは使えない）

1. プリンターの電源を切った状態で、背面の USB の差し込み口にケーブルを挿す
2. ワイヤクリップでケーブルを留めて、プリンターの電源を入れる
3. ケーブルのもう一方を iPad・iPhone に挿す

## 4. Airレジのアプリで設定して、保存する

1. ホーム画面の「設定」→「レジ・プリンター」を開く

![Airレジのホーム画面の設定から、レジ・プリンターを開く配置図](/images/posts/airregi-printer-drawer-setup-step4.webp)

2. 「プリンター利用」をオンにして、「プリンター」から「セイコーインスツル RP-F10」を選ぶ
3. 「レシート紙幅」を、セットした紙と同じ幅（80mmか58mm）にする
4. 画面右下の「保存する」をタッチし、「保存しました」と出れば接続の設定は完了

![レジ・プリンター画面で、プリンター利用・プリンター・レシート紙幅を選び、右下の保存するを押す配置図](/images/posts/airregi-printer-drawer-setup-step5.webp)

同じ「レジ・プリンター」画面には、会計のたびにレシートを自動で印刷する「会計レシート自動印刷」のスイッチもあります。会計のときにドロアを自動で開けたい場合は、この画面の「キャッシュドロア利用」を有効にします（公式ヘルプ「レジ点検・精算の利用方法」）。公式ヘルプでは、「設定」→「レシート」の画面で「保存してレシートをテスト印刷する」にチェックを入れて保存する、テスト印刷の方法も案内されています。

## 5. ためしに1回会計して、ドロアとレシートを確かめる

公式動画では、設定のあとに**ためしに一度会計してみる**ことをすすめています。

1. 画面左上のボタンでホーム画面に戻る
2. 「注文入力・会計」をタッチし、商品を選んで「支払いへ進む」
3. 預かり金額を入れて「会計する」をタッチする
4. ドロアが開いて、レシートが印刷されれば、接続の設定は正しくできています

![お支払いの画面で会計するを押し、お会計を完了しましたと出るまでの配置図](/images/posts/airregi-printer-drawer-setup-step7.webp)

### テストの会計は、その日のうちに消す

テストの会計が売上に入らないよう、**当日中に伝票を削除**しておきましょう。日付が変わると、前の日の伝票は削除できなくなります。

1. ホーム画面の「点検・精算」から「レジ締め前伝票一覧」をタッチする
2. テストで会計した伝票を選ぶ
3. 「削除する」をタッチする

![点検・精算からレジ締め前伝票一覧を開き、テストの伝票を選んで削除するを押す配置図](/images/posts/airregi-printer-drawer-setup-step8.webp)

削除すると、取り消しのレシートが印刷されます。一度削除した伝票は元に戻せないので、伝票の時刻と金額を見てから押しましょう。

公式ヘルプによると、一度設定すれば、Airレジのアプリを起動するたびにプリンターが自動でつながります。

## つながらないときは

公式動画によると、プリンターと正しくつながっていないときは、Airレジのホーム画面の左上にあるアイコンに赤いマークが出ます。開店前にこのマークが出ていないかを見るのを、朝の習慣にしておくと安心です。

![ホーム画面の左上、設定更新の右のアイコンに赤いマークが出ている配置図](/images/posts/airregi-printer-drawer-setup-step6.webp)

印刷できないときは、まず電源、紙の向き、紙幅の設定が合っているかを見直しましょう。Bluetooth がつながらないときの確かめ方は[POSレジのBluetooth機器がつながらない時の対処法](/posts/pos-bluetooth-not-connecting)に、レジ別の確認手順は[レシートプリンターが印刷できないときの確認手順](/posts/receipt-printer-not-printing)にまとめています。

## よくある質問

### Q. ドロアは iPad とBluetoothでつなぎますか

公式動画の組み合わせ（RP-F10とDRW-A01）では、ドロアは付属のケーブルでプリンターにつなぎます。iPad とつなぐのはプリンターだけです。

### Q. 紙幅はあとから変えられますか

公式ヘルプでは、使い始めたあとに紙幅を切り替えると故障の原因になるとしています。最初にどちらで使うか決めてからセットしましょう。

## まとめ

AirレジとRP-F10・DRW-A01の接続は、ケーブルでプリンターとドロアをつなぐ → ロール紙を入れる → Bluetoothか有線で iPad とつなぐ → アプリの「レジ・プリンター」で選んで保存 → ためしに会計してドロアとレシートを確かめる → テストの伝票は当日中に削除、の順です。買う前に型番（USB type-C PD モデル）を、使い始める前に紙幅を確かめておくのがポイントです。
