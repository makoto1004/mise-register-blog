ペットショップでは、フードや用品の物販、生体（犬・猫などの動物）の販売、トリミング、ペットホテルと、会計の種類がいくつも重なります。予約はカレンダー、物販はレジ、ホテルの記録は別のノートとなっていると、どこに何を書いたか迷いやすいですよね。

![ペットショップのカウンターにタブレットのレジがあり、フードの棚・リード・ペットのベッド・トリミング台があるイラスト](/images/posts/pet-shop-pos-1.webp)

POSレジ（会計と商品の情報をまとめて記録するレジ）にすると、何がまとめられて、何は別に管理し続ける必要があるのでしょうか。この記事では、ペットショップで楽になることと、POSでは代われない法律上の決まりを分けて紹介します。ほかの業種もまとめた[普通のレジからPOSレジにすると良くなること](/posts/pos-benefits-by-industry)もあわせてどうぞ。

## ガチャレジと手書きの記録で困りがちなこと

ガチャレジや電卓、手書きの台帳では、会計の種類ごとに記録がばらばらになりがちです。あとから「この飼い主さんが前に買ったフードはどれだったか」「どの商品が残り少ないか」を調べるとき、いくつもの記録を見比べることになります。

| よくある作業 | 困りやすいこと |
| --- | --- |
| フード・用品の会計 | 同じ銘柄でも容量や味が違い、打ち間違えやすい |
| 在庫の確認 | 棚を見て数えるので、気づいたら品切れしている |
| トリミング・ホテル | 予約の内容を、会計のときにあらためて確かめる |
| 飼い主さんへの対応 | 前回の利用や購入の記録を探すのに時間がかかる |

業務が増えるほど、記録の置き場所が増えていきます。まずは「どこで手間がかかっているか」を見つけるところから始めてみましょう。

## POSレジにすると変わること

POSレジでは、商品やサービスを登録して会計し、売れた記録と在庫を残せます。フード・用品・トリミング・ホテルを一つのレジで会計できれば、1日の売上をまとめて見られるようになります。

| 業務 | POSレジで楽になること | 確かめたい点 |
| --- | --- | --- |
| フード・用品 | 商品ごとの売れた数と残りの数が分かる | 容量・味・サイズを別の商品として登録できるか |
| 生体販売 | 1頭ごとの会計の記録が残る | 生体の管理システムと連携できるか |
| トリミング | コースや追加のメニューをボタンで会計できる | 予約の内容を会計に引き継げるか |
| ペットホテル | 預かりの料金を会計できる | 利用時間ごとの料金を予約側で扱えるか |

フードの在庫を商品ごとに管理すれば、残り少ない商品に早めに気づけます。JANコード（商品についている共通のバーコード）を読み取るバーコードリーダーがあれば、容量違いの打ち間違いも減らせます。機器の選び方は[バーコードリーダーの比較](/posts/barcode-scanner-comparison)や[POSレジの周辺機器のそろえ方](/posts/pos-peripherals-guide)で紹介しています。

スマレジは、ペットショップ向けの解説で、生体の管理システムや仕入れの管理システムとの連携、購入後のフォローの記録、売れ筋の分析、フード・用品の在庫の確認などを挙げています。生体・物販・トリミングを一つのレジで扱えるかを、導入のときに確かめる点としています。

### 予約と会計をつなぐ

トリミングやホテルの予約は、予約サービスとPOSの組み合わせで考えるのが一般的です。たとえばSquareは、ペットサービス向けに予約の受付、メールやSMSでのリマインド、顧客カルテ、決済、無料のPOSレジアプリをまとめて案内しています。Airリザーブは、トリミングサロンやペットホテルのネット予約、前日のリマインド、利用時間に応じた料金設定ができ、同じ店舗でAirレジを使うと顧客情報が共有されて、会計の回数や履歴を確認できると案内しています。

予約サービスの料金は、2026年10月時点で次のとおりです（決済手数料などは別）。

| サービス | 予約の料金プラン（2026年10月時点） |
| --- | --- |
| Square 予約 | フリー 0円（1店舗まで）、プラス 月額3,000円、プレミアム 月額8,000円（いずれも店舗ごと） |
| Airリザーブ | フリー 0円、ベーシック 月額5,500円（税込）、スタンダード 月額11,000円（税込） |

どこまでつながるか（予約の内容が会計に入るのか、顧客情報だけが共有されるのか）は、サービスによって違います。ふだんの受付から会計までの流れに沿って、試してみるのが確実です。

## POSでは代われないこと：動物愛護管理法でお店が行うこと

ここは大事なところなので、はっきり分けておきます。POSレジが受け持つのは、会計、物販の在庫、顧客や予約の記録です。動物を売るときに法律で決められた説明や記録、登録を、POSが代わりにしてくれるわけではありません。

| 決まり（環境省の案内より） | 内容の要点 | POSとの関係 |
| --- | --- | --- |
| 現物確認・対面説明 | 哺乳類・鳥類・爬虫類を売るときは、前もって事業所で動物を直接見せ、特徴や飼い方を対面で文書（データを含む）を使って説明する。ネットだけで売買契約を成立させることはできない | POSは関わらない。お店の接客の手順として行う |
| 説明の項目 | 品種、大人になったときの大きさ、平均寿命、かかりやすい病気と予防、病歴・ワクチンの接種状況など18項目 | 説明の文書はお店で用意する |
| 帳簿と定期報告 | 品種・繁殖者・生年月日・購入先・販売先など13項目を帳簿に記載して5年間保存。毎年度5月30日までに、前年度の所有数・販売数などを届け出る | POSの売上記録とは別に、決められた形で残す |
| マイクロチップ | 令和4年6月1日から、販売される犬・猫への装着が義務。ペットショップは仕入れ後30日以内、かつ販売までに変更登録。購入者は購入後30日以内に所有者の変更登録 | POSは関わらない。購入者への手続きの説明もお店で行う |

このほか、犬・猫の販売業者には56日齢以下の販売制限などの決まりもあります。また、ペットホテルは「保管業」の例とされ、トリミングでも動物を預かる場合は保管業の例に挙げられています。登録が必要な種別や、細かな決まりは、お店のある都道府県などの動物愛護管理の担当窓口で確かめてください。

生体をPOSで扱う場合は、1頭ずつ別の商品として登録し、売れたら在庫が0になるようにする方法があります。ただ、健康状態や仕入れの情報、法律で残す記録まで含めた個体の管理は、専用の生体管理システムを使うお店が多いです。POSとどこまで連携できるかを確かめておきましょう。

## 選ぶときに見ておきたいポイント

| 確かめる点 | 見ておきたいこと |
| --- | --- |
| 物販の在庫 | 容量・味・サイズを分けて登録でき、JANコードを読み取れるか |
| 予約と会計 | トリミング・ホテルの予約や顧客情報を、会計に引き継げるか |
| 飼い主とペットの情報 | 飼い主の連絡先とペットの情報を、必要な範囲で残せるか |
| 生体の管理 | 生体管理システムと連携できるか。できない場合の記録の分け方 |
| 支払い方法 | 生体などの高い買い物で、使いたい支払い方法に対応しているか |
| スタッフの権限 | 返金や商品登録などの操作を、担当によって制限できるか |
| 個人情報 | 誰が顧客情報を見られるか、スタッフが辞めたときに権限を外せるか |

費用を抑えて始めたいときは[低コストで始めるPOSレジ](/posts/pos-low-cost-start)も参考にしてみてください。補助金のことは、まとめ記事の[普通のレジからPOSレジにすると良くなること](/posts/pos-benefits-by-industry)で紹介しています。

## 導入の順番

1. 物販・生体・トリミング・ホテルの会計と、今の記録の置き場所を書き出します。
2. 商品の登録のルールを決めます。フードの容量や味、用品のサイズ、生体の1頭ごとをどう分けるかを考えます。
3. 予約サービスや生体管理システムと、どこまでつながるかを確かめます。顧客情報がどこに保存されるかも見ておきましょう。
4. まず物販だけ、トリミングだけなど一部で使い、会計と在庫の記録が現場に合うかを確かめます。
5. スタッフ向けの操作の手順をそろえてから、ほかの業務に広げます。

法律で残す記録（帳簿・説明の文書・マイクロチップの手続き）は、POSを入れても今までどおり続けます。導入のときに「POSで記録するもの」と「別に残すもの」を一覧にしておくと、引き継ぎで迷いません。

## よくある質問

### 生体の販売もPOSレジで管理できますか？

会計や販売の記録はPOSレジで残せます。1頭ずつ別の商品として登録する方法もあります。ただ、仕入れや健康状態、法律で決められた帳簿まで含めた管理は、専用のシステムや決められた帳簿で行うのが一般的です。

### トリミングやホテルの予約と会計はつながりますか？

予約サービスとPOSの組み合わせによって違います。顧客情報が共有されるだけのこともあれば、予約の内容を会計に引き継げることもあります。つながらない部分は、予約番号を会計のメモに入れるなど、お店のルールで補いましょう。

### POSレジを入れれば、法律の記録や手続きも済みますか？

済みません。現物確認・対面説明、動物の帳簿と定期報告、マイクロチップの変更登録は、お店が法律にもとづいて行うことです。POSや予約の記録とは分けて管理してください。

## まとめ

- POSレジで、フード・用品の在庫と、物販・トリミング・ホテルの会計を一か所にまとめやすくなる
- 予約と会計がどこまでつながるかは、サービスの組み合わせで違うので、ふだんの流れで試す
- 現物確認・対面説明、動物の帳簿、マイクロチップの登録はPOSでは代われない。お店の手順として続ける
- 困っている業務から小さく始めて、記録の分け方を決めてから広げる
