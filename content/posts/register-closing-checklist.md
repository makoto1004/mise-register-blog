閉店後は疲れていて、細かな確認を後回しにしたくなることがあります。そんな時間でも、決まった順番で迷わず締められるように、無料の「レジ締めチェック表」を用意しました。印刷して手書きできるPDF版と、入力を助けるExcel版があります。

お店の中で自由にコピーして使えます。再配布・販売はご遠慮ください。

## チェック表でできること

- 現金を数え、今日の売上などから計算した金額と比べられます。
- POSレジと決済サービスの管理画面を見比べて、キャッシュレス決済の金額を確認できます。キャッシュレスとは、現金を使わない支払い方法のことです。
- 差額が出たときに確認することと、店じまいの確認を同じ用紙にまとめられます。

金額を記録する欄だけでなく、確認した人や気づいたことを書く欄もあります。締め作業の記録を、翌日の確認にも役立てられます。

## チェック表の中身

| 欄 | 書くこと | 分かること |
|---|---|---|
| 0 締める前 | 取り消し・返品の伝票、送られていない会計データ | 締める前に直すべき所 |
| 1 現金 | 金種ごとの枚数と金額、金庫へ移した現金 | 数えた現金（A） |
| 2 計算 | 釣り銭（B）・現金の売上（C）・入金（D）・出金（E） | あるはずの現金（F）と差額 |
| 3 カード等 | キャッシュレスと商品券の金額（レジと管理画面） | 支払い方法ごとの「差」 |
| 4 確認 | 差額が出たときの8つの確認と、気づいたこと | ずれた理由の手がかり |
| 5 店じまい | 翌日の釣り銭・取り出す売上金・鍵 | 閉店時の確認もれ |

金種表（きんしゅひょう）は、お札と硬貨の種類ごとに枚数を書く表です。

## 毎日の使い方

1. **日付などを記入します。** 用紙の上にある日付、レジ、締めた人、確かめた人の欄を埋めます。1人で締める場合は、確かめた人の欄を空欄にしてもかまいません。
2. **締める前に、POSレジの画面を確かめます。** 取り消し・返品・訂正の伝票に問題がないか、送られていない会計データがないかを見ます。直さないまま締めると、あるはずの金額と実際の現金がずれる原因になります（Airレジの公式FAQでも、精算の前の確認として案内されています）。
3. **現金を数えます。** 金種ごとの枚数を書きます。営業中に金庫などへ移した現金があれば、その金額も書いて合計Aに入れます。商品券やクーポン券は、現金とまぜずに分けて数えましょう。
4. **あるはずの現金を計算します。** Bには開店時の釣り銭を記入します。準備金とは、営業開始時にレジに用意しておく釣り銭です。CにはPOSレジに記録された現金の売上、Dには両替などの入金、Eには買い出しなどの出金を書きます。Fと差額を計算し、AとFを比べます。
5. **キャッシュレスを見比べます。** クレジットカード、QRコード決済、電子マネー、商品券などごとに、POSレジと決済サービスの管理画面の金額を書き、「差」を出します。
6. **差額があれば上から確かめます。** 8つの確認を、用紙の上から順に見ていきます。

| 確かめること | 見るところ |
|---|---|
| 金種ごとに数え直した | お札の重なり、硬貨の積み方、商品券がまざっていないか |
| 金庫などへ移した現金も数えた | 交代のときの伝え忘れ |
| 開店時の釣り銭（B）がいつもと同じ | 入れ忘れ・記録とちがう金額 |
| 入金・出金（D・E）をすべて記録した | 両替や、現金での小さな支払い |
| キャッシュレスを「現金」で登録していない | 3の表の「差」が0か |
| 会計忘れ・二重の会計・取り消し忘れがない | 取引の一覧。返品のときに現金を戻したか |
| 値引き・クーポンがレジに入っている | 口頭で値引きして、入れ忘れていないか |
| 差額が、どれかの会計のお釣りと同じではない | お釣りの渡し間違い・渡し忘れの手がかり |

金種・準備金の入力ミス、支払い方法の間違い、会計忘れや二重の会計、お釣りの渡し間違いは、スマレジの公式ヘルプでも現金過不足の主なケースとして挙げられています。理由や気づいたことは欄に残します。
7. **店じまいをします。** 翌日の釣り銭を残し、その金額を書きます。毎日同じ金額に決めておくと迷いません。残りの「A－翌日の釣り銭」が、取り出す売上金です。出入口と小さな窓の鍵も確かめます。
8. **記入した用紙を保管します。** 精算レシートといっしょに、日付順に見返せる形でとじておきます。Excel版は日付が分かる名前で保存すると、後から探しやすくなります。

## Excel版の使い方

枚数や金額を入力すると、現金の合計や差額の計算を補助します。セルとは、表の中で文字や数字を入力するマスのことです。

| 入れるもの | 自動で出るもの |
|---|---|
| 金種ごとの枚数、金庫へ移した現金 | 各金種の金額と合計（A） |
| B〜Eの金額 | F（あるはずの現金）と差額、「合っています」「多い」「少ない」の表示 |
| キャッシュレスの金額（レジと管理画面） | 支払い方法ごとの「差」（0でなければ赤く表示） |
| 翌日の釣り銭 | 取り出す売上金（A－翌日の釣り銭） |

確認の欄は、「済」を選んで記録できます。

Googleスプレッドシートでも開けます。ファイルを開いたら、金種ごとの枚数とB〜Eの金額を入力し、表示された合計や差額を確認してください。計算結果とレジや管理画面の記録も見比べましょう。

## 差額が出たときの考え方

差額が出ても、すぐに原因を決めつける必要はありません。数え方や記録を順に確かめ、気づいたことを残しておきましょう。翌日以降も記録があれば、いつから金額が合わなくなったかを追いやすくなります。

同じくらいの差が続く場合は、特定の作業や記録の手順にくせがある可能性も考えられます。入金・出金の記録方法や、返品時の現金の扱いなどを見直すきっかけにできます。理由が分からないときも、差額と確認した内容をそのまま残しておくと、後から見返せます。

## よくある質問

### 手書きとExcel、どちらがいいですか？

紙で作業したい場合はPDF版、入力や計算を補助したい場合はExcel版が使いやすいでしょう。締め作業のときに書きやすい方法を選び、毎日続けられる形にしましょう。

### 2人で確かめる必要はありますか？

2人で確認できる場合は、締めた人と確かめた人を記録できます。1人のお店でも使えます。その場合も、日付と金額だけは残しておきましょう。後から記録を見返す手がかりになります。

### 何日分保管すればよいですか？

保管期間は、帳簿の扱いと関係します。お店の状況によって確認が必要な場合があるため、税務署や税理士に確かめてください。

合わないときの確認手順は[レジ締めで現金が合わないときの確認手順](/posts/register-cash-mismatch)で、閉店後の現金の扱いは[閉店後の現金はどうする？金庫の置き場所と店じまいのルール](/posts/store-cash-closing-rules)で紹介しています。
