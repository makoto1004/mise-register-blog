農産物直売所では、出荷者（生産者）から預かった野菜や加工品を売る委託販売が中心です。閉店後に出荷者ごとの売上を集計し、手数料を引いて精算する作業は、手書きと電卓だと時間がかかりますよね。

![農産物直売所の野菜の棚と、バーコードのラベルを貼った袋、ラベルプリンターとタブレットのレジのイラスト](/images/posts/farm-stand-pos-1.webp)

POSレジ（会計と商品の情報をまとめて記録するレジ）に、直売所向けの仕組みを組み合わせると、ラベルの発行から集計・精算・出荷者への連絡までをつなげやすくなります。ただ、ふつうのPOSレジだけでは足りない機能もあります。この記事では、直売所で楽になることと、選ぶときに確かめたい点を紹介します。ほかの業種もまとめた[普通のレジからPOSレジにすると良くなること](/posts/pos-benefits-by-industry)もあわせてどうぞ。

## 手書きの値札と手計算で起きやすいこと

ガチャレジや電卓を使っていると、会計の記録から「誰の商品がいくつ売れたか」を後で拾い出す必要があります。値札を手で書いたり、価格や出荷者の違うシールを貼り間違えたりする心配もあります。

| よくある作業 | 困りやすいこと |
| --- | --- |
| 値札を付ける | 出荷者ごとに値札を手書きし、貼り間違いが起きる |
| 会計 | レジで出荷者を打ち分けるのが手間で、間違えると集計がずれる |
| 売上の集計 | 閉店後に出荷者ごとに数え直す |
| 精算・支払い | 手数料の計算、精算書づくり、振込の準備が重なる |
| 出荷者への連絡 | 売り切れや売れ残りが、その日のうちに伝わらない |

品数の多い時期ほど、手数料の計算や書き写しで間違えていないかを確かめる手間が増えていきます。

## 直売所向けの仕組みで変わること

直売所向けのPOSシステムでは、出荷者が持ち込むときにバーコード付きのラベルを発行し、レジでそのラベルを読み取って売ります。ラベルに商品・出荷者・価格の情報が入っているので、読み取るだけで出荷者ごとの売上が集計されます。

| 作業 | 直売所向けシステムでできることの例 |
| --- | --- |
| 値札・ラベル | 出荷者が端末で商品と価格を選び、バーコードラベルを印刷する |
| 会計 | ラベルを読み取ると、出荷者・商品名・価格がレジに出る |
| 売上の連絡 | 出荷者専用のサイトやメールで、売れ行きを知らせる |
| 精算 | 手数料を引いた精算額を計算し、精算書を作る |
| 支払い | 精算額から振込用のデータを作る（対応する製品の場合） |

農林水産省が紹介した道の駅「筆柿の里幸田」（愛知県）の事例では、出荷者がPOS端末でバーコードシールを作って貼り、レジで読み取った数量と金額を出荷者別に集計していました。出荷者は売上報告のメールで売れ行きを確かめ、午前に出荷して昼のメールを見てから午後にも出荷する、翌日の量を増やすといった判断をしているそうです。一方で、保守契約の費用が高いことも課題として挙げられていました。平成25年の調査なので、今の製品の機能や費用とは違いますが、仕組みのイメージをつかむのに役立ちます。

今の製品では、たとえばビジコムの直売所向けシステムは、ラベル発行、1日5回（時刻は直売所が設定）の売上速報メール、出荷者ごとの精算の自動計算、店舗一律または商品・出荷者ごとの手数料率の設定を案内しています。スマレジは、直売所向けシステム「アグリーン」との連携で、バーコードシールの発行、農家へのメールでの販売情報の共有、委託手数料の自動計算、精算書の発行、振込用の全銀データの作成を案内しています。

## ふつうのPOSレジだけでは足りないこと

一般的なPOSレジは、会計や売上の記録にはとても便利です。ただ、出荷者ごとの委託精算や、出荷者が自分で使うラベル発行機は、標準の機能に入っていないことが多いです。直売所向けのシステムや連携アプリを足す必要があるかを、各社の公式情報で確かめておきましょう。

また、出荷の登録にかかわる確認（栽培や防除の記録など）は、レジの会計とは別の仕事です。先ほどの事例では、職員が栽培日誌・防除日誌を確かめて出荷登録に反映し、確認がない出荷者の商品はレジを通らないようにしていました。システムでどこまで扱えるか、誰が確認するかを決めておくと安心です。

### インボイスの扱い

インボイス（適格請求書）も確かめておきたい点です。国税庁のQ&Aでは、委託を受けて売る側（直売所）が、自分の名前と登録番号で出荷者の代わりに適格請求書を出せる「媒介者交付特例」は、出荷者と直売所の両方が適格請求書発行事業者であること、出荷者が登録を受けていることを取引の前までに直売所へ知らせていることが条件とされています。出荷者が登録しているかどうかで扱いが変わるので、ラベルや精算で区別できるかを製品ごとに確かめましょう（ビジコムは、システム連動タイプでインボイス対象の商品にマークを付けたラベルを出せると案内しています）。直売所の運営の形によっても違うので、詳しくは税務署や税理士に相談してください。レシートの書き方は[お店のレシートとインボイス](/posts/receipt-invoice-for-shops)でも紹介しています。

### 消費税率の変更への備え

飲食料品の消費税率を、令和9年4月1日から令和11年3月31日まで1%に引き下げる法案が、国会に出ています（2026年10月時点。まだ決まったものではありません）。成立すれば、レジの税率の設定を変える必要が出てきます。野菜や加工品を扱う直売所には関係の深い話なので、税率の変更にどう対応してもらえるか（設定の手順、サポートの範囲、費用）も、選ぶときに聞いておくと安心です。この変更への対応を支える補助金の枠も公表されていますが、内容は今後変わる可能性があります。補助金のことはまとめ記事の[普通のレジからPOSレジにすると良くなること](/posts/pos-benefits-by-industry)で紹介しています。

## 選ぶときに見ておきたいポイント

| 確かめる点 | 見ておきたいこと |
| --- | --- |
| ラベル発行 | 持ち込みのときに迷わず使えるか。年配の出荷者にも分かりやすいか |
| 売上速報 | サイト・メールなど、出荷者が見やすい方法で届くか。時刻を決められるか |
| 手数料 | 店舗一律か、商品・出荷者ごとに設定できるか |
| 精算と支払い | 精算書（一覧・内訳）と振込用データを作れるか |
| インボイス | 出荷者の登録の有無を区別できるか |
| 費用と保守 | 月額・機器代・設定費・保守の範囲がはっきりしているか |
| 税率変更 | 税率が変わったときの設定変更とサポートの範囲 |

料金は、2026年10月時点の公式ページでも、プランや機器によってかなり違います。参考までに、ビジコムは月額10,000円〜28,000円（税別、POSの月額込み）の3つのプランを載せていて、機器代やプランによってはサーバー設定費が別にかかります。スマレジ×アグリーンは1店舗の例で、初期費用16.5万円、月額31,900円（税込）とし、iPadなどの機器と導入設定費は別としています。載っている金額だけで決めず、機器・設定・保守まで含めた見積もりで比べましょう。

## 導入の順番

1. **今の作業を書き出す**：値札づくり、集計、手数料の計算、精算書、振込、出荷者への連絡を並べます。
2. **減らしたい作業を決める**：ラベル発行、出荷者別の集計、売上速報、精算書、振込データのどれが一番重いかを見ます。
3. **出荷者と一緒に試す**：ラベルの発行や売上の確認を、実際に使う出荷者に触ってもらいます。
4. **費用と分担を比べる**：機器代・月額・設定費・保守に加え、出荷者の登録や問い合わせを誰が受けるかを決めます。
5. **一部から始める**：最初は一部の出荷者や商品で使い、精算額を今までの方法と見比べてから広げます。

ラベルの貼り間違いや価格の登録もれが起きたときの直し方も、先に決めておくと現場で慌てずに済みます。

## よくある質問

### ふつうのPOSレジに替えるだけで、出荷者ごとの精算もできますか？

できるとは限りません。POSレジの標準の機能と、直売所向けのシステムや連携アプリの機能を分けて確かめてください。手数料の設定や精算書の出力まで、自分の直売所のやり方に合うかを見ることが大切です。

### 出荷者がスマートフォンを使っていない場合は？

メールや専用サイトのほかに、どんな知らせ方があるかを提供元に聞いてみましょう。事務所で印刷して渡すなど、直売所の側で補う方法もあります。出荷者が無理なく見られる形を選びたいですね。

### 補助金は使えますか？

制度の中身や対象は、年度や公募の回によって変わります。補助金のことはまとめ記事の[普通のレジからPOSレジにすると良くなること](/posts/pos-benefits-by-industry)で紹介しています。申請の前に、最新の公募要領や相談窓口で確かめてください。

## まとめ

- 直売所向けのシステムを使うと、ラベル発行から出荷者別の集計・精算・振込データまでをつなげやすい
- 売上速報は、出荷者が追加の出荷や翌日の量を決める手がかりになる
- ふつうのPOSレジだけでは委託精算やラベル発行が足りないことが多いので、連携の範囲を確かめる
- インボイスの扱い、税率変更への対応、保守費用も含めて比べ、小さく試してから広げる
