カフェの物件は「雰囲気がよい」「家賃が手ごろ」で決めたくなります。ただ、契約してから「排気ダクトが通せない」「電気の容量が足りない」と分かると、工事費が大きくふくらんでしまいます。

この記事では、**立地**・**必要な設備**・**間取り**の3つの観点から、契約前に見ておきたいポイントをまとめました。

## 立地：人通りの「数」より「質」を見る

人通りが多くても、カフェに入る人が通るとは限りません。見るべきなのは、**お店のコンセプトに合う人が、来てほしい時間帯に通っているか**です。

| 見るポイント | 確認のしかた |
| --- | --- |
| 客層 | 平日・休日、朝・昼・夕方に現地に立って、通る人の年代や様子を見る |
| 時間帯 | モーニング中心なら通勤の流れ、ランチ中心ならオフィスや学校の近さ |
| 入りやすさ | 1階か、道路から店内が見えるか、入口に段差がないか |
| 周りのお店 | 同じようなカフェが近くに多すぎないか。逆に、人が集まる店が近くにあるか |
| 駐車場・駐輪場 | 車や自転車で来るお客様が多い地域では特に大切 |

**ポイント**：1回の下見で決めず、曜日と時間を変えて何度か見に行きましょう。

## 必要な設備：工事費を左右するところ

### 1. 給排水とグリストラップ

シンクや製氷機を置くには、給水・排水の配管が必要です。飲食店では、排水に含まれる油を止める**グリストラップ**の設置が求められることがあります。今ある設備と、追加の工事が必要かを確認しましょう。

### 2. 排気（換気・ダクト）

調理で出る煙やにおいを外に出す**排気ダクト**を通せるかは、物件によって大きく違います。ビルの構造上ダクトを通せない、近隣への配慮で制限がある、という場合もあるので、**フードメニューを出すなら必ず確認**しましょう。

### 3. 電気とガス

- **電気の容量**：エスプレッソマシン・オーブン・冷蔵庫・空調などを同時に使うと、容量が足りないことがあります。業務用の機器には「動力（三相200V）」が必要なものもあります
- **ガス**：都市ガスかプロパンガスか、使いたい機器に合うかを確認します
- **POSレジ・Wi-Fi**：インターネット回線の工事には日数がかかることがあります。開業日に間に合うよう、早めに申し込みましょう（[店舗のネットワーク配線ガイド](/posts/store-network-setup)）

### 4. 保健所の基準に合う設備

飲食店の営業許可には、手洗い設備やシンクの数、床や壁の素材などの基準があります。基準は地域によって違うことがあるので、**物件を決める前に、図面を持って管轄の保健所に相談**しておくと安心です。

## 間取り：客席と厨房のバランス

![カフェ（約10坪）のレイアウト例。入口の右にレジと受取カウンター、右奥に厨房、左に2人掛けテーブル4卓、窓際にカウンター席4席](/images/layouts/cafe-layout.svg)

10坪ほどのカフェなら、たとえば上のような配置が考えられます。入ってすぐに注文・会計ができ、テイクアウトのお客様はそのまま入口へ戻れるので、イートインのお客様と動線がぶつかりません。

### 客席と厨房の配分

客席を増やしすぎると、厨房が狭くなって作業が回らなくなります。テイクアウト中心なら客席は少なめに、イートイン中心なら客席を多めにと、**お店の売り方から逆算**して決めましょう。

### 動線を確認する

- **お客様の動線**：入口 → 注文・レジ → 受け取り → 席、が交わらずに流れるか
- **スタッフの動線**：厨房 → カウンター → 客席を、お客様とぶつからずに行き来できるか
- **レジの位置**：入口から見える位置にあると、注文の流れが分かりやすい

テーブルとチェアの選び方や通路の幅は[個人カフェのテーブル＆チェアの選び方](/posts/cafe-table-set)で解説しています。

## 居抜き物件とスケルトン物件

| 種類 | メリット | 注意点 |
| --- | --- | --- |
| 居抜き（前のお店の設備が残っている） | 内装・設備の費用を抑えやすい。開業までが早い | 設備が古い・壊れていることがある。前のお店の印象が残る |
| スケルトン（何もない状態） | 自由にお店をつくれる | 内装・設備の工事費が高くなりやすい。工事期間が長い |

居抜きの場合は、残っている設備が**譲り受けか、リースか**、壊れていないかを必ず確認しましょう。

## 契約前のチェックリスト

- [ ] 曜日と時間を変えて、何度か現地を見た
- [ ] 飲食店として使ってよい物件か、管理会社・大家さんに確認した
- [ ] 給排水・排気ダクト・グリストラップの設置ができるか確認した
- [ ] 電気の容量・ガスの種類が、使いたい機器に足りるか確認した
- [ ] 図面を持って保健所に相談した
- [ ] 内装工事の見積もりを取った（家賃だけで判断しない）
- [ ] 看板を出してよい場所・大きさを確認した

開業にかかる費用全体は、記事の最後の初期費用シミュレーターで計算できます。そろえる機材は[カフェ開業時の必要機材リスト](/posts/cafe-opening-equipment)も参考にしてください。

## よくある質問

### 家賃はどのくらいが目安ですか？

見込みの売上に対して、家賃が重くなりすぎないようにするのが基本です。売上の見込みは控えめに立てて、家賃を払っても続けられるか計算しておきましょう。

### 2階の物件でもカフェはできますか？

できますが、通りからお店が見えにくく、入りにくさがあります。看板や外階段の見せ方を工夫したり、目的を持って来てもらえるお店づくりをしたりする必要があります。

### 住宅を改装してカフェにできますか？

用途地域や建物の用途によって、できる場合とできない場合があります。また、面積によっては用途変更の手続きが必要になることがあります。役所の建築担当の窓口や専門家に相談しましょう。

## まとめ

- 立地は人通りの数より、来てほしいお客様が来てほしい時間に通るかで判断する
- 給排水・排気・電気・ガスは工事費を大きく左右するので、契約前に確認する
- 間取りは、お店の売り方から客席と厨房の配分を決め、動線を確認する
- 物件を決める前に、図面を持って保健所に相談する
