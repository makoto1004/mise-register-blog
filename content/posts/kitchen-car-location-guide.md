キッチンカーには、お店の「物件」はありません。そのかわりに、**どこで売るか（出店場所）**、**どこで準備するか（仕込み場所）**、**どこに停めておくか（駐車場）**の3つを選ぶ必要があります。キッチンカーを始めるときに、いちばん悩みやすいところかもしれません。

この記事では、店舗の物件選びでいう「立地・設備・間取り」を、キッチンカー向けに置き換えて解説します。

| 店舗の物件選び | キッチンカーでは |
| --- | --- |
| 立地 | 出店場所 |
| 必要な設備 | 仕込み場所・車両の設備・駐車場 |
| 間取り | 車内のレイアウト |

## 出店場所（立地）：売れる場所の見つけ方

### 主な出店場所

| 出店場所 | 特徴 |
| --- | --- |
| イベント・マルシェ | 人が多く集まる。出店料がかかり、競合のキッチンカーも多い |
| オフィス街・商業施設の空きスペース | 平日のランチ需要がある。場所を紹介するサービスや、施設との契約で出店する |
| 住宅地・公園の近く | 夕方や休日の需要がある。地域の決まりの確認が必要 |

### 出店場所を選ぶポイント

- **客層とメニューが合うか**：オフィス街なら早く受け取れるランチ、イベントなら写真映えするメニュー
- **時間帯**：お客様が集まる時間に、確実に営業できるか
- **競合**：同じ場所に似たメニューのキッチンカーがいないか
- **電源・水**：会場で電源を借りられるか、使えないなら自前で用意できるか

**注意**：道路や公園、私有地などで勝手に営業することはできません。必ず、場所の管理者の許可を取った場所で出店しましょう。

## 仕込み場所と車両の設備：営業許可に関わるところ

キッチンカーで食品を販売するには、保健所の**営業許可**が必要です。

- **仕込み場所**：メニューによっては、車の外の「仕込み施設」で下ごしらえをする必要があります。仕込みができる場所の条件も、保健所の確認が必要です
- **車両の設備**：シンク、給水・排水タンクの大きさ、手洗い設備などに基準があります
- **営業できる地域**：許可を出した保健所の管轄によって、営業できる地域が決まります。複数の地域で営業したい場合は、どの手続きが必要かを確認しましょう

基準や手続きは地域や時期によって違うことがあるので、**車を作る前、仕込み場所を決める前に、管轄の保健所に相談**しましょう。車の入手方法は[キッチンカーの始め方](/posts/kitchen-car-build-franchise)、[キッチンカーレンタルの種類と相場](/posts/kitchen-car-rental)で解説しています。

## 駐車場：意外と見落としやすい条件

キッチンカーを停めておく駐車場も、事前に確保が必要です。

- **車の大きさ**：車高・車幅・長さが入るか。立体駐車場や機械式駐車場は入らないことが多い
- **仕込み場所との距離**：毎日の移動が負担にならないか
- **防犯**：夜間に車を停めておくので、明るさや人目があるか（[お店の防犯グッズの選び方](/posts/store-crime-prevention)）
- **電源**：冷蔵庫などのために、駐車中に電源を使えるとよい

## 車内のレイアウト（間取り）

![キッチンカーの車内レイアウト例。販売窓の内側の左に注文・会計、右に受け渡し、運転席側に2槽シンク、後ろ側に鉄板・フライヤー、奥の壁に作業台を兼ねた冷蔵庫](/images/layouts/kitchen-car-layout.svg)

立ち位置から体の向きを変えるだけで「冷蔵庫から出す → 調理 → 受け渡し」ができる配置にすると、狭い車内でも動きに無駄が出にくくなります。

狭い車内では、**作業の順番どおりに機器を並べる**と、行列が速く進みます。

```
注文・会計（販売窓のそば） → 調理 → 盛り付け → 受け渡し（販売窓）
```

- **会計の位置**：POSレジと決済端末は販売窓のそばに。お客様に画面を見せやすい位置に固定する
- **調理の位置**：火や油を使う場所は、販売窓から離して安全に
- **動線**：スタッフが2人以上なら、すれ違えるか確認する

会計まわりの機材は[キッチンカーのキャッシュレス決済の選び方](/posts/kitchen-car-cashless)、[屋外イベント用・持ち運び機材セット](/posts/kitchen-car-event-equipment)で紹介しています。

## 開業前のチェックリスト

- [ ] 出店できる場所を、少なくとも数か所見つけた（管理者の許可あり）
- [ ] 出店場所ごとの客層・時間帯・競合を確認した
- [ ] 車を作る前に、保健所に営業許可の基準を相談した
- [ ] 仕込みが必要なメニューの場合、仕込み場所を確保した
- [ ] 車の大きさに合う駐車場を確保した
- [ ] 車内のレイアウトを、作業の順番どおりに決めた

開業にかかる費用全体は、記事の最後の初期費用シミュレーターで計算できます。

## よくある質問

### 出店場所はどうやって探せばよいですか？

イベントの出店募集、商業施設やオフィスビルとの契約、キッチンカーと場所をつなぐサービスなどがあります。最初は複数の方法を組み合わせ、売れる場所を少しずつ増やしていきましょう。

### 自宅の駐車場に停めてもよいですか？

車の大きさが入り、近所の迷惑にならなければ停められます。ただし、自宅のキッチンを仕込み場所として使えるかは、保健所の基準によります。

## まとめ

- キッチンカーの「物件選び」は、出店場所・仕込み場所・駐車場の3つ
- 出店場所は、客層・時間帯・競合・電源と水で選び、必ず管理者の許可を取る
- 営業許可の基準は、車を作る前・仕込み場所を決める前に保健所に相談する
- 車内は、注文 → 調理 → 受け渡しの順に機器を並べる
