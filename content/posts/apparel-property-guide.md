アパレルショップや雑貨店は、**お店の前を通る人に、商品を見て入ってもらう**ことが売上の入口です。そのため、物件選びでは「通りからどう見えるか」と「店内をどう歩いてもらうか」が大切になります。

この記事では、**立地**・**必要な設備**・**間取り**の3つの観点から、契約前に確認したいポイントをまとめます。

## 立地：ターゲットが「ついでに寄れる」場所か

| 見るポイント | 確認のしかた |
| --- | --- |
| 通る人の層 | お店のターゲット（年代・好み）に合う人が通っているか。休日と平日の両方で見る |
| 周りのお店 | 雰囲気の近いお店や、人が集まるお店が近くにあると、ついでに寄ってもらいやすい |
| 通りからの見え方 | ショーウィンドウや入口から、店内の商品が見えるか |
| 入りやすさ | 入口の広さ、段差の有無、扉を開けっぱなしにできるか |
| 搬入のしやすさ | 商品の段ボールを運び込める通路・駐車スペースがあるか |

**ネットショップと両方で売る場合**は、家賃を抑えた立地にして、その分をネットの集客に回す考え方もあります。

## 必要な設備：照明と電気で商品の見え方が変わる

### 1. 照明

服の色や素材感は、照明で大きく変わります。スポットライトを付けられるダクトレールがあるか、追加の工事ができるかを確認しましょう。照明の選び方は[アパレル店舗什器・ディスプレイ家具の選び方](/posts/apparel-display-rack)でも紹介しています。

### 2. 電気の容量とコンセントの位置

照明・エアコン・衣類スチーマー・POSレジ・ラベルプリンターなどを使います。**レジを置きたい場所にコンセントがあるか**も確認しておくと、配線工事を減らせます。

### 3. インターネット回線

POSレジやネットショップの在庫連携には、安定した回線が必要です。回線の工事は日数がかかることがあるので、早めに申し込みましょう（[店舗のネットワーク配線ガイド](/posts/store-network-setup)）。

### 4. 水まわり

飲食店や美容室ほどの設備はいりませんが、スタッフ用のトイレや手洗い場があるか確認しましょう。

## 間取り：売り場・試着室・在庫スペースの配分

![アパレル・雑貨店（約10坪）のレイアウト例。入口の正面に低い丸テーブル、中央に平台、左の壁にハンガーラック、右の壁に雑貨の棚、左奥に試着室、右奥にレジ](/images/layouts/apparel-layout.svg)

中央の什器のまわりをぐるりと回れる配置にすると、店内の商品をひととおり見てもらいやすくなります。

### 売り場の動線

```
入口 → 目玉商品（ネスティングテーブルなど） → 壁沿いのラック → 試着室 → レジ
```

- **入口付近**：新作やおすすめを置き、店内に入るきっかけをつくる
- **奥**：定番商品や、試着が必要な商品を置き、店の奥まで歩いてもらう
- **通路**：お客様がすれ違える幅を確保する

### 試着室

試着室は、**売り場から近く、レジからも目が届く位置**が理想です。鏡を置く場所と、着替えに十分な広さを取れるか確認しましょう。

### 在庫スペース（バックヤード）

アパレルはサイズ・カラーごとに在庫を持つため、思ったより在庫スペースが必要になります。売り場を広く取りすぎて、在庫の置き場がなくならないようにしましょう。

### レジの位置

入口と店内全体が見渡せる位置に置くと、接客と防犯の両方に役立ちます。防犯の考え方は[お店の防犯グッズの選び方](/posts/store-crime-prevention)で解説しています。

## 契約前のチェックリスト

- [ ] 休日・平日に現地を見て、ターゲットに合う人が通るか確認した
- [ ] 通りから店内が見えるか、看板を出せるか確認した
- [ ] 照明（ダクトレール）・コンセントの位置・電気の容量を確認した
- [ ] 試着室と在庫スペースを取れる広さか、図面で確認した
- [ ] 商品の搬入ルートを確認した
- [ ] 古着を扱う場合、古物商の許可の手続きを確認した

開業にかかる費用全体は、記事の最後の初期費用シミュレーターで計算できます。そろえるものは[アパレルショップ開業に必要なもの一覧](/posts/apparel-opening-checklist)にまとめています。

## よくある質問

### 路面店と商業施設のテナント、どちらがよいですか？

路面店は自由にお店づくりができる一方、集客は自分で行う必要があります。商業施設のテナントは人が集まりやすい一方、営業時間や内装にルールがあり、売上に応じた費用がかかることもあります。

### 狭い物件でもアパレルショップはできますか？

できます。壁面のラックや、高さを活かした什器を使うと、狭い物件でも商品を見やすく並べられます。在庫は売り場に出しすぎず、バックヤードやネットショップと分けて管理しましょう。

## まとめ

- 立地は、ターゲットが「ついでに寄れる」場所か、通りから商品が見えるかで判断する
- 照明・コンセント・回線は、商品の見え方とレジまわりの使いやすさに関わる
- 間取りは、売り場の動線・試着室・在庫スペースのバランスで考える
