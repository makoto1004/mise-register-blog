美容室の物件選びは、立地だけでなく、**シャンプー台の水まわり**と**電気の容量**、そして**美容所として届け出られる基準**を満たせるかが大切です。契約してから工事ができないと分かると、計画が大きく狂ってしまいます。見落としやすい設備の条件もあるので、内見の前に一度目を通しておくと安心です。

![大きな窓のある空き物件。壁ぎわのシャンプー台と配管、手前に広げた図面とメジャーのイラスト](/images/posts/salon-property-guide-1.webp)

この記事では、**立地**・**必要な設備**・**間取り**の3つの観点から、契約前に確認したいポイントをまとめます。

## 立地：予約で来るお店か、通りがかりで入るお店か

美容室は予約して来店するお客様が多い業種です。そのため、カフェほど人通りの多さにこだわらなくてもよい一方、**通いやすさ**と**見つけやすさ**が大切になります。

| 見るポイント | 確認のしかた |
| --- | --- |
| 通いやすさ | 駅やバス停からの距離、駐車場の有無（車で来るお客様が多い地域か） |
| 見つけやすさ | 初めてのお客様が迷わずに来られるか。看板を出せる場所があるか |
| 客層 | 周りに住んでいる人・働いている人の年代が、お店のターゲットと合うか |
| 周りのお店 | 近くの美容室の数と、価格帯・雰囲気の違い |
| 1階か2階以上か | 1階は見つけてもらいやすい。2階以上は家賃を抑えやすく、落ち着いた雰囲気をつくりやすい |

## 必要な設備：水まわりと電気が最重要

### 1. シャンプー台の給排水・給湯

シャンプー台には、給水・排水・お湯の配管が必要です。

- **排水**：シャンプー台の位置まで排水管を引けるか（床を上げる工事が必要になることもある）
- **給湯**：営業中にお湯を使い続けられる**給湯器の容量**があるか。シャンプー台の数が多いほど大きな容量が必要になる

### 2. 電気の容量

ドライヤー・デジタルパーマの機器・エアコンを同時に使うと、電気の容量が足りなくなることがあります。**使う機器と台数から、必要な容量を電気工事の業者に確認**しましょう。

### 3. 換気と明るさ

カラー剤やパーマ液のにおいを外に出す換気が必要です。施術する場所の明るさにも、美容所としての基準があります。

### 4. 美容所の届け出の基準

美容室を開くには、保健所に美容所の開設届を出し、検査を受ける必要があります。作業室の広さ、消毒の設備、換気、明るさなどに基準があり、地域によって細かいところが違うことがあります。**物件を決める前に、図面を持って管轄の保健所に相談**しましょう。

### 5. インターネット回線

予約システムやPOSレジ、カルテ用のiPadを使うなら、安定した回線が必要です。回線の工事は日数がかかることがあるので、早めに申し込みましょう（[店舗のネットワーク配線ガイド](/posts/store-network-setup)）。

## 間取り：セット面・シャンプー台・受付の配置

![美容室（約10坪）のレイアウト例。入口の近くに受付と待合、右の壁沿いにセット面3台、左奥の間仕切りの中にシャンプー台2台、右奥にバックルーム](/images/layouts/salon-layout.svg)

シャンプー台を入口から見えにくい奥に置くと、お客様が落ち着いて過ごせます。

### お客様の流れで考える

```
入口 → 受付・待合 → セット面（カット・カラー） → シャンプー台 → セット面（仕上げ） → 受付（会計）
```

この流れの中で、**お客様が何度も行き来しても狭く感じないか**、**スタッフがすれ違えるか**を確認します。

### 配置のポイント

- **シャンプー台**：水まわりの配管に近い場所に置くと、工事費を抑えやすい
- **セット面**：鏡の前と後ろに、スタッフが動ける余裕を取る
- **受付・待合**：入口の近くに。セット面から待合が丸見えにならないよう、仕切りや向きを工夫する
- **バックヤード**：タオルの洗濯・乾燥、材料の在庫を置く場所も必要

待合スペースの家具は[美容室の待合スペースに置きたいソファ＆ミニテーブル](/posts/salon-waiting-sofa)、受付のiPadなどは[美容室の周辺機器とカルテ用iPadの選び方](/posts/salon-ipad-peripherals)で紹介しています。

## 居抜き物件を選ぶときの注意

前も美容室だった居抜き物件は、シャンプー台の配管や電気の容量がそろっていることが多く、費用を抑えやすいです。ただし、

- シャンプー台・給湯器が古くないか、壊れていないか
- 残っている設備が譲り受けか、リースか
- セット面の数や配置が、自分のお店の計画に合うか

を必ず確認しましょう。

## 契約前のチェックリスト

- [ ] 美容室として使ってよい物件か、管理会社・大家さんに確認した
- [ ] シャンプー台の位置まで排水・給湯の配管を引けるか確認した
- [ ] 給湯器の容量と、電気の容量が足りるか確認した
- [ ] 図面を持って保健所に相談した（美容所の基準）
- [ ] 内装工事の見積もりを取った
- [ ] 看板を出してよい場所・大きさを確認した

## よくある質問

### 1人で営業するなら、どのくらいの広さが必要ですか？

セット面とシャンプー台の数、待合の広さ、美容所の基準で決まります。まずは置きたい設備を決め、図面に配置してみて、保健所の基準も確認しましょう。

### マンションの一室でも開業できますか？

物件の規約で店舗としての利用が認められていない場合があります。また、水まわりや電気の工事ができるかも確認が必要です。管理会社・大家さんに必ず確認しましょう。

## まとめ

- 美容室の立地は、人通りより「通いやすさ」と「見つけやすさ」を重視する
- シャンプー台の給排水・給湯と、電気の容量は工事費を大きく左右する
- 間取りは、お客様の流れ（受付 → セット面 → シャンプー台 → 会計）で考える
- 物件を決める前に、図面を持って保健所に相談する
