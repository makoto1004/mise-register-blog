POSレジの売上明細を月ごとに集計すると、売上が増減した理由や、忙しい時間帯、よく売れる商品が見えてきます。この記事では、架空のカフェの2026年9月・10月の見本を使い、Excelで確認する手順を紹介します。売上の数字を、次の営業に活かしましょう📊

## 売上明細を7列にそろえる

売上明細とは、POSレジから書き出した、会計や商品ごとの記録です。まずはお使いの POS レジから明細を出し、次の7列に並べて1つの表にします。列の順番はPOSレジによって異なるため、必要に応じて並べ替えてください。

| 列 | 入れる内容 |
|---|---|
| 日付 | 会計があった日 |
| 時刻 | 会計があった時刻 |
| 会計番号 | レシート番号、取引IDなど |
| 商品名 | 販売した商品名 |
| 数量 | 販売した数 |
| 売上金額（税込） | 商品ごとの税込金額 |
| 支払い方法 | 現金、クレジットカードなど |

会計番号があれば、同じ会計番号の行をまとめて1会計として数えられます。客数と客単価を出すときは、この会計数を客数として扱います。会計番号が明細にない場合は、客数や客単価を正確に出せません。

返品や取り消しは、金額をマイナスにして売上から差し引きます。架空のカフェの見本では、10月15日にチーズケーキ1個の返品があり、金額は−550円です。返品の行は売上から差し引きますが、客数には数えません。

明細がCSV（カンマで区切った文字のファイル）で、Excelで開いたときに文字化けした場合は、Excelの［データ］→［テキストまたは CSV から］を使って読み込み、文字コードを選び直します。

## 今月と前月を比べる（売上＝客数×客単価）

前月比とは、今月の数字が前月に比べて何％増えたか、または減ったかを表す割合です。売上だけでなく、客数、客単価、営業日数も並べて確認しましょう。

| 指標 | 2026年10月 | 2026年9月 |
|---|---:|---:|
| 売上 | 1,284,330円 | 1,107,700円 |
| 客数（会計の数） | 868人 | 750人 |
| 客単価 | 1,480円 | 1,477円 |
| 営業日数 | 27日 | 25日 |

架空のカフェの見本では、10月の売上は9月より15.9%増えています。客単価はほぼ同じで、客数が増えています。また、営業日数も2日多いため、売上を営業日数で割った「1日あたりの売上」も見てみましょう。

| 月 | 売上 | 営業日数 | 1日あたりの売上 |
|---|---:|---:|---:|
| 2026年10月 | 1,284,330円 | 27日 | 約47,568円 |
| 2026年9月 | 1,107,700円 | 25日 | 44,308円 |

売上は「客数 × 客単価」に分けて考えられます。客数が増えたのか、客単価が上がったのかを分けて見ると、変化の理由を考えやすくなります。売上の数字を日々の改善につなげる考え方は、[POSのデータでお店のPDCAを回す](/posts/shop-pdca-pos-data)でも紹介しています。

## 時間帯・曜日で見る

時間帯別の集計では、0時から23時までの各時間について、売上・客数・客単価を出します。架空のカフェの見本では、10月は12時台の売上が最も多く、184,400円、客数は124人です。

| 時間帯 | 10月の売上 | 10月の客数 |
|---|---:|---:|
| 12時台 | 184,400円 | 124人 |

混み合う時間帯が分かったら、その前に仕込みを済ませたり、人の配置を厚くしたりする判断に使えます。空いている時間帯は、提供する商品の見せ方や売り方を考えるきっかけになります。

曜日別では、曜日ごとの売上合計と、売上のあった日だけで割った1日平均を出します。火曜定休のように営業しない曜日を0円として平均に入れると、営業日の売上が低く見えてしまうためです。

## 商品別ランキングとABC分析

商品別ランキングは、商品ごとの売上を多い順に並べたものです。構成比とは、ある商品の売上が全体の売上に占める割合です。累積構成比は、ランキング上位から構成比を足し上げた割合です。

ABC分析とは、売上への貢献度に応じて商品をA・B・Cに分ける方法です。ここでは累積構成比が70%までの商品をA、90%までをB、それより下をCとします。70%・90%はよく使われる目安で、決まった基準ではありません。商品を足す前の累積構成比で判定するため、1位の商品は必ずAになります。

| 区分 | 架空のカフェの10月の商品 |
|---|---|
| A | 季節のパフェ、ナポリタン、ホットサンド、カフェラテ、チーズケーキ |
| B | ブレンドコーヒー、アイスティー |
| C | クッキー |

架空のカフェの見本では、1位は季節のパフェで、売上は293,700円です。Excelでは商品ごとの売上を多い順に並べ、全体売上に対する構成比と累積構成比を計算してから区分します。

| 商品 | 販売価格 |
|---|---:|
| 季節のパフェ | 1,100円 |
| ナポリタン | 950円 |
| ホットサンド | 780円 |
| チーズケーキ | 550円 |
| カフェラテ | 520円 |
| アイスティー | 480円 |
| ブレンドコーヒー | 450円 |
| クッキー | 280円 |

Aの商品は、品切れを防いだり、見つけやすい場所に置いたりする候補になります。Cの商品は、ついで買いにつながっているか、価格や見せ方を見直せるかを考えます。Cだからといって、すぐに販売をやめる必要はありません。

## 支払い方法ごとに見る

支払い方法別に金額と割合を集計すると、どの方法で売上が多いかを確認できます。現金、クレジットカード、QRコード決済、電子マネーを分けて集計しましょう。

| 支払い方法 | 集計する内容 |
|---|---|
| 現金 | 売上金額、全体に占める割合 |
| クレジットカード | 売上金額、全体に占める割合 |
| QRコード決済 | 売上金額、全体に占める割合 |
| 電子マネー | 売上金額、全体に占める割合 |

支払い方法別の集計は、決済手数料を見直すときや、釣り銭の準備を考えるときに役立ちます。割合は「支払い方法ごとの金額 ÷ 全体の売上」で求められます。

## レジ締めの差額を毎日1行で記録する

レジ締めとは、営業終了後に現金や決済の記録を確認し、売上と実際の金額が合っているか確かめる作業です。現金は、次の項目を1日1行で記録します。

| 項目 | 記録する内容 |
|---|---|
| A | 数えた現金 |
| B | 開店時の釣り銭 |
| C | 現金の売上 |
| D | 入金 |
| E | 出金（買い出しなど） |
| F | あるはずの現金（B＋C＋D−E） |
| 差額 | A−F |
| 判定 | 合っています・多い・少ない |

買い出しなどで現金を使った場合は、出金として記録します。架空のカフェの見本では、5日の1,200円と21日の860円を出金として記録しているため、その金額は差額にはなっていません。

10月のレジ締め記録を集計すると、締めた日は27日、差額が出た日は3日でした。多かった金額の合計は100円、少なかった金額の合計は−1,500円です。キャッシュレス決済では、売上明細と決済サービスの管理画面を見比べ、差が出た日は1件でした。

| 日 | 見つかったこと | 対応・メモ |
|---|---|---|
| 9日 | QRコード決済の会計を現金で登録。現金が1,000円少なく、QRの管理画面が1,000円多い | 翌日に取引を修正 |
| 17日 | 現金が500円少ない。お釣りの渡し間違いの可能性 | 翌日の朝礼で共有 |
| 23日 | 現金が100円多い。数え直しても同じ | 原因は分からず |

差額が出た日と内容を月ごとに並べると、支払い方法の入力間違いなど、同じ原因が繰り返されていないか確認できます。毎日の確認方法は[レジ締めチェック表（無料）](/posts/register-closing-checklist)を参考にできます。現金が合わない日の確認手順は[レジ締めで現金が合わないとき](/posts/register-cash-mismatch)をご覧ください。

## Excelで作るときのコツ

集計には、条件に合う行だけを合計するSUMIFSや、条件に合う行数を数えるCOUNTIFSが使えます。操作に慣れている場合は、ピボットテーブルで集計しても構いません。

明細は1か月ごとに同じシートへ貼り付け、集計する年と月を指定して切り替えられる形にしておくと、毎月の作業を貼り付け中心にできます。入力するセルと数式が入ったセルを色分けすると、誤って数式を消すのを防ぎやすくなります。

売上明細や集計表は、お店で使う端末やネットワークとあわせて管理しておくと、どこに何があるか分かりやすくなります。[お店の IT 機器の管理表の作り方](/posts/store-it-ledger-guide)も参考にしてください。

## よくある質問

### 客数はどう数えますか？

会計番号がある場合は、同じ番号の明細を1会計として数えます。この会計数を客数として扱います。会計番号がない明細では客数を出せません。

### 返品があったときはどう集計しますか？

返品は金額をマイナスにして売上から差し引きます。客数には加えません。架空のカフェの見本では、10月15日のチーズケーキ1個を−550円として記録しています。

### 定休日は曜日別の平均に含めますか？

売上のあった日だけで割った1日平均を出します。定休日を0円として平均に含めると、営業日の傾向が分かりにくくなるためです。

## まとめ

- 売上明細は7列にそろえ、会計番号・返品・支払い方法を確認します。
- 売上を客数と客単価に分け、営業日数や時間帯、商品別でも比べます。
- レジ締めの差額は毎日記録し、金額と原因の傾向を月ごとに確認します。

この記事の見本は、運営者が BOOTH で販売している Excel テンプレート[売上集計シート](/posts/shop-excel-templates)の記入例です。自分で作る場合は、この記事の手順と表の形をそのまま使えます。
