リサイクルショップでは、同じ「Tシャツ」でも状態や値段が1点ずつ違います。値札を手で書き、買取のたびに古物台帳へ記入し、売れた品を台帳や棚から探す。こうした作業が重なると、営業の合間に記録を続けるのは大変ですよね。

![リサイクルショップのカウンターにタブレットのレジとラベルプリンターがあり、値札の付いたラジオ・カメラ・かばん・椅子が並ぶイラスト](/images/posts/recycle-shop-pos-1.webp)

POSレジ（会計と商品の情報をまとめて記録するレジ）に替えると、1点ごとの在庫や販売の記録をまとめて扱いやすくなります。買取や古物台帳の記録を手伝う仕組みもあります。ただ、法律で決められた確認まで、POSに任せきりにできるわけではありません。この記事では、リサイクルショップで変わることと、導入前に確かめたい点を紹介します。ほかの業種もまとめた[普通のレジからPOSレジにすると良くなること](/posts/pos-benefits-by-industry)もあわせてどうぞ。

## ガチャレジと手書き台帳で起きやすいこと

ガチャレジや電卓は会計には使えますが、商品の状態や買取額、売値を一緒に管理するのは得意ではありません。手書きの台帳と組み合わせていると、会計の記録と買取の記録を別々に探すことになります。

| よくある作業 | 困りやすいこと |
| --- | --- |
| 値札を付ける | 状態も価格も1点ずつ違い、値札を1枚ずつ書く |
| 販売する | どの商品が売れたか、棚を見ないと分からない |
| 買取を記録する | 品目・特徴・相手方の情報を台帳に手書きし、書きもれを確かめる |
| レジを締める | 買取で払った現金が売上と別の記録になり、差額の理由を追いにくい |

買取の記録と在庫がつながっていないと、買い取った後に台帳と商品の一覧へ同じことを二度書くことにもなります。現金が合わないときの確かめ方は[レジ締めで現金が合わないときの確認手順](/posts/register-cash-mismatch)で紹介しています。

## POSレジにすると変わること

POSレジでは、商品ごとに価格や状態を登録し、会計のときに売れた商品を記録できます。1点ずつを別の商品として見分ける「単品管理（個品管理とも呼ばれます）」を使えば、「Tシャツが何枚あるか」だけでは分からない、1点ごとの動きを追えます。

| 店頭の場面 | POSでできることの例 |
| --- | --- |
| 商品登録 | 商品名・状態・価格などを1点ごとに登録する |
| 値札付け | 単品のバーコード付きラベルを印刷し、商品と登録情報を結びつける |
| 販売・棚卸し | バーコードを読み取って販売を記録し、在庫を確かめる |
| 買取の後 | 買取の情報から商品を作り、そのまま在庫に入れる（買取アプリと連携する場合） |

たとえば同じ型のバッグがいくつかあっても、傷や付属品の違いを1点ごとに記録しておけば、会計のときに取り違えにくくなります。バーコードで棚卸しをすれば、商品を1点ずつ探して数える手間も減らせます。機器をそろえるときは[POSレジの周辺機器のそろえ方](/posts/pos-peripherals-guide)や[バーコードリーダーの比較](/posts/barcode-scanner-comparison)も参考にしてみてください。

買取の機能は、POSに連携するアプリで足す形が多いです。たとえばスマレジの「買取オプション」では、査定の受付番号や商品ラベルの発券、買取申込書の印刷、本人確認書類の保管、タッチペンでの署名、買取後の在庫登録、古物台帳の検索・出力・払い出し（販売の記録）が案内されています。ラベルの印刷には対応するバーコードプリンターが必要とされています。使える機能や必要な機器はサービスで違うので、自分のお店の流れに合うかを確かめましょう。

## 古物営業法との関係：POSが受け持つこと、お店が確かめること

中古品を買い取って売るには、古物商の許可と、古物営業法の決まりを守ることが前提です。POSや買取アプリは「記録の手間を減らす道具」で、法律に合っているかの判断まではしてくれません。

| 古物営業法の決まり（要点） | POS・買取アプリで手伝えること | お店が確かめること |
| --- | --- | --- |
| 買い取るとき、相手の住所・氏名・職業・年齢を確かめる（第15条） | 身分証の画像の保管、署名の入力 | 確認の方法が法律に合っているか、画像の安全な保管 |
| 受け取った古物の記録：取引の年月日、品目と数量、特徴、相手の住所・氏名・職業・年齢、とった確認の方法（第16条） | 買取データを台帳として保存・検索・出力 | 必要な項目がすべて残るか |
| 記録は3年間保存。データで残すなら、営業所ですぐ紙に出せるようにする（第18条） | 台帳の出力・印刷 | 営業所にプリンターなどがあるか |
| 不正品の疑いがあるときは、すぐ警察官に申告（第15条3項） | ― | 申告の流れをスタッフで決めておく |

買い取る総額が1万円未満なら、確認と記録は原則いりません。ただし、1万円未満でも必要な物があります。施行規則では、バイク・原付（部品を含む）、家庭用ゲームソフト、CD・DVDなど、書籍、エアコンの室外機・電気温水機器のヒートポンプ、電線、金属製のグレーチングが決められています。室外機から後ろの4つは、2025年10月1日の改正で加わったものです。

売ったとき（払い出し）の記録が必要なのは、美術品類、時計・宝飾品類、自動車、バイク・原付などに限られています。扱う品目によって必要な記録が変わるので、自分のお店の品ぞろえで確かめておくと安心です。

台帳をPOSやアプリのデータで残してよいか、項目は足りているかは、お店の運用と合わせて管轄の警察署（生活安全課など）に確かめてください。都道府県の条例で、年少者からの買受けに決まりがある場合もあるので、各都道府県警のページも見ておきましょう。

## 選ぶときに見ておきたいポイント

| 確かめる点 | 見ておきたいこと |
| --- | --- |
| 単品管理 | 状態・価格を1点ごとに登録でき、売れたら在庫が0になるか |
| ラベル発行 | バーコード付きの値札を、使いたい大きさで印刷できるか |
| 買取機能 | 買取アプリと連携でき、買取の後に在庫へ入るか |
| 台帳の出力 | 必要な項目を検索・出力でき、営業所で印刷できるか |
| 個人情報 | 身分証の画像を誰が見られるか、権限を分けられるか |
| ネット販売・スタッフ | ネットショップと在庫を合わせたいか、スタッフごとに操作を制限できるか |

料金は、POS本体・買取アプリ・ラベルプリンターなどの機器で分かれることが多いです。比べるときは、2026年10月時点の情報を各社の公式ページで確かめ、それぞれの費用を分けて見ると迷いにくくなります。費用を抑える考え方は[低コストで始めるPOSレジ](/posts/pos-low-cost-start)で紹介しています。補助金のことはまとめ記事の[普通のレジからPOSレジにすると良くなること](/posts/pos-benefits-by-industry)をご覧ください。

## 導入は小さく試してから

1. 買取・商品登録・値札付け・販売・棚卸し・台帳記録の流れを書き出します。
2. どの作業をPOSにまとめたいか、台帳に残す項目と出力の形を決めます。
3. 候補のサービスで、単品管理・買取後の在庫登録・台帳の出力を、ふだんの流れに沿って試します。
4. 台帳をデータで残す方法を、管轄の警察署に確かめます。
5. 一部の商品やスタッフから使い始め、値札・会計・在庫・記録がつながるかを見てから広げます。

## よくある質問

### POSレジがあれば、古物台帳を手で書かなくてよいですか？

古物営業法は、帳簿に書くほか、パソコンなどのデータで記録することも認めています。ただし、必要な項目がすべて残ること、営業所ですぐ紙に出せることが条件になります。使うPOSやアプリとお店の運用で足りているかは、管轄の警察署に確かめてください。

### 1万円未満の買取なら、本人確認はいりませんか？

原則はいりませんが、すべての品目ではありません。ゲームソフトや書籍、CD・DVD、バイクの部品などは、1万円未満でも確認と記録が必要です。古着や家具が中心のお店でも、本やゲームを一緒に買い取ることはよくあるので、品目ごとに整理しておきましょう。

### 小さなお店でもPOSレジに替えたほうがよいですか？

商品の数や買取の件数が少なく、今の台帳と在庫の管理で困っていなければ、急いで替える必要はありません。値札の書き直しや、売れた商品の確認、二度書きに時間がかかっているなら、必要な機能にしぼって費用と手間を比べてみる価値があります。

## まとめ

- POSレジの単品管理とバーコードラベルで、1点ものの値札・会計・棚卸しがつながる
- 買取アプリを連携すると、買取から在庫登録、台帳の出力までの二度書きを減らせることがある
- 古物営業法の確認・記録・保存が足りているかは、サービスの説明だけで決めず、管轄の警察署に確かめる
- 負担の大きい作業から、小さく試して広げる
